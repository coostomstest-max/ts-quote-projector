# [Wiki] Extensión de Modelos de Proyección: Suavizado Exponencial Simple (SES)

## 📋 Descripción General
El **Suavizado Exponencial Simple (SES)** es un algoritmo de pronóstico de series de tiempo que asigna ponderaciones exponencialmente decrecientes a las observaciones pasadas. Se integra al sistema para calcular estimaciones de cotizaciones financieras (`compra` y `venta`) en fechas específicas donde no se dispone de un registro real en la base de datos, actuando como un mecanismo de resolución de lagunas o proyecciones a futuro sin la rigidez de una interpolación polinomial.

---

## 📐 Especificación Lógica y Arquitectura

El sistema debe procesar un arreglo estructurado bajo el tipo `Cotizacion`:

```typescript
export type Cotizacion = {
    fecha: string;        // ISO string, ej "2025-09-17"
    compra: number;
    venta: number;
    currency?: string;    // Opcional
};
```

### 1. Módulo Core: `interpolation.service.ts`
Aloja la función matemática pura del algoritmo. Debe procesar un arreglo plano de números (para que sea reutilizable) y un factor de suavizado \(\alpha\) (Alfa).

*   **Fórmula de recurrencia:** \(\hat{Y}_{t+1} = \alpha Y_t + (1 - \alpha) \hat{Y}_t\)
*   **Condición inicial:** \(\hat{Y}_1 = Y_1\)
*   **Comportamiento de Extrapolación:** Si se requiere proyectar múltiples períodos hacia el futuro (más allá del último dato disponible), el SES mantiene un valor constante igual a la última predicción calculada: \(\hat{Y}_{t+n} = \hat{Y}_{t+1}\).

### 2. Módulo de Negocio: `exchProjector.basic.service.ts`
Orquesta la lógica de negocio mediante un método privado que expone la predicción basada en fechas.
1.  **Ordenamiento:** Asegurar que el array de `Cotizacion` esté estrictamente ordenado de forma cronológica por `fecha`.
2.  **Búsqueda Directa:** Verificar si la fecha solicitada ya existe en el historial. Si existe, retorna sus valores directamente.
3.  **Procesamiento SES:** Si la fecha no existe, extrae los vectores numéricos históricos de `compra` y `venta`, invoca al servicio `InterpolationService` y retorna el objeto proyectado `{ compra, venta }`.

```text
TASK: Implementar el algoritmo de Suavizado Exponencial Simple (SES) distribuido entre InterpolationService y ExchProjectorBasicService.

REQUISITOS DE IMPLEMENTACIÓN:

1. En 'interpolation.service.ts':
   - Crear el método público `calcularSES(datos: number[], alpha: number = 0.3): number`.
   - Debe validar que `datos.length > 0`. Si tiene longitud 1, retornar ese único valor.
   - Implementar el bucle iterativo de SES sin mutar el array original.
   - Retornar el valor flotante con la predicción final esperada para el siguiente paso (t+1).

2. En 'exchProjector.basic.service.ts':
   - Inyectar o hacer disponible `InterpolationService`.
   - Implementar un método privado (ej. `obtenerOProyectarCotizacion(historial: Cotizacion[], fechaObjetivo: string): { compra: number, venta: number }`).
   - LÓGICA:
     a) Ordenar 'historial' por 'fecha' de forma ascendente.
     b) Buscar si existe un elemento donde `fecha === fechaObjetivo`. Si existe, retornar `{ compra: elemento.compra, venta: elemento.venta }`.
     c) Si no existe, filtrar el historial para conservar solo las cotizaciones con 'fecha' ANTERIOR o IGUAL a 'fechaObjetivo' (para no usar datos del futuro en la predicción).
     d) Extraer el array de números para 'compra' y el array para 'venta' de las cotizaciones filtradas.
     e) Invocar a `interpolationService.calcularSES` de forma independiente para cada array (compra y venta) usando un alpha por defecto de 0.3.
     f) Retornar un objeto con el formato `{ compra: resultadoCompra, venta: resultadoVenta }`.

CRITERIOS DE ACEPTACIÓN:
- El código debe estar escrito en TypeScript tipado correctamente.
- El método en 'exchProjector.basic.service.ts' debe ser privado y estar listo para ser invocado internamente.
- No se deben redondear los valores intermedios para preservar la precisión de coma flotante de JavaScript.
```
