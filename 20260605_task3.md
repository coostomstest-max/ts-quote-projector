TAREA PARTE 3: ADICIÓN DE SPLINE CÚBICO MONÓTONO EN 'interpolation.service.ts'
-------------------------------------------------------------------------------
Objetivo: Implementar un método de interpolación de Spline Cúbico Monótono (Algoritmo de Fritsch-Carlson) para estimar con alta precisión valores faltantes dentro de una serie de tiempo, evitando oscilaciones artificiales (Efecto Runge) y garantizando que la curva respete estrictamente los máximos y mínimos locales históricos.

REQUISITOS DE IMPLEMENTACIÓN EN 'interpolation.service.ts':

1. Crear el método público:
   `calcularSplineMonotono(x: number[], y: number[], xObjetivo: number): number`
   - 'x': Array de números que representan la variable independiente ordenada (en nuestro contexto serán los índices de tiempo o timestamps transformados a números).
   - 'y': Array de números con los valores de las cotizaciones asociados a cada punto de 'x'.
   - 'xObjetivo: El punto numérico intermedio que deseamos interpolar.

2. Restricciones y Validaciones:
   - Validar que `x.length` sea igual a `y.length` y que `x.length >= 2`.
   - Si `xObjetivo` coincide exactamente con un valor dentro del array 'x', retornar de inmediato el valor correspondiente de 'y' (Bypass de cálculo).
   - El método debe validar que 'x' se encuentre estrictamente ordenado de forma ascendente.

3. Lógica del Algoritmo (Fritsch-Carlson):
   - Paso A (Pendientes Secantes): Calcular las pendientes entre puntos adyacentes: d_i = (y_{i+1} - y_i) / (x_{i+1} - x_i).
   - Paso B (Pendientes Tangentes iniciales): Calcular la media matemática de las secantes adyacentes para cada punto interno.
   - Paso C (Restricción de Monotonía): Si una pendiente secante d_i es 0, forzar que las tangentes en los extremos de ese intervalo sean 0 (esto evita que el precio "dibuje" curvas falsas si el valor se mantuvo plano). Ajustar las tangentes usando la fórmula modificada de Fritsch-Carlson para asegurar que no se creen picos artificiales fuera del rango de los datos reales.
   - Paso D (Interpolación Cúbica Hermite): Localizar el intervalo en el que cae `xObjetivo` (i tal que x_i <= xObjetivo <= x_{i+1}) y aplicar el polinomio cúbico de Hermite utilizando las posiciones, los valores de 'y' y las pendientes tangentes ya corregidas.

4. Criterio de Aceptación Técnico:
   - El código debe ser 100% puro en TypeScript, sin librerías externas de matemáticas (implementación nativa).
   - No mutar los arrays 'x' ni 'y' provistos por el cliente.
   - Retornar el valor flotante con la máxima precisión matemática nativa del motor de JS/TS.
